# Gety Tools Directory

This directory can hold external optional binary helpers used by Gety:

- `yt-dlp.exe`: For extracting and downloading online streaming video and audio (YouTube, Vimeo, etc.).
- `ffmpeg.exe`: Optional converter for media formats.

*Note:* If not present here, Gety also automatically discovers `yt-dlp` from your Windows system `PATH` or `WinGet` installation.
